# Secure Browser

One desktop browser for enabled partner workspaces.

Download the current installer from [Releases](https://github.com/x-project-coding/secure-browser-releases/releases/latest).

## macOS

The Mac installer supports Apple silicon and Intel. It is signed with a Developer ID and notarized by Apple.

1. Download the DMG, open it, and drag Secure Browser into Applications.
2. Open your workspace setup link, or enter the app address supplied by your team.
3. Sign in and approve access on your workspace’s website.

Your workspace administrator must enable Secure Browser before you can sign in. Contact your workspace administrator for help.

This repository distributes installers and update files. Application source is maintained separately.
